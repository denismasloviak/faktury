Zoznam

Maily posiela raz denne GitHub Action podľa tohto zoznamu. Zmena sa prejaví do 24 hod.

Pripoj sync

Vlož token a odteraz sa zoznam faktúr sám prenáša medzi zariadeniami — a GitHub Action z neho vie posielať maily.

  1. github.com → Settings → dole Developer settings
  2. Personal access tokens → Tokens (classic) → Generate new token
  3. Zaškrtni gist — bez toho to nepôjde
  4. Skopíruj ho sem ↓

Sync

Token sa ukladá len v tomto prehliadači. Dáta sú v privátnom Gist-e (súbor faktury.json).
